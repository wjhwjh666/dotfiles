## 接入方案：alibaba/open-code-review（只写方案，未执行安装）

> 命令按 2026-09-26 的 README（v1.12.9）核对过。

```bash
# 1. 安装 CLI（Win11 Git Bash）；要求 Git >= 2.41
npm install -g @alibaba-group/open-code-review

# 2. 审查
ocr review                            # 工作区里所有已暂存、未暂存、未跟踪的改动
ocr review --from master --to <分支>   # 分支从 master 分出后的改动
ocr scan --path <目录>                 # 不看 diff，整文件审查
```

**LLM 用委派模式（推荐）**：`ocr delegate ...` 只负责挑文件、套规则，审查由 Claude Code 自己完成，不用另配 LLM Key，符合"只走官方订阅"。项目还自带 Claude Code 插件（仓库 `plugins/open-code-review`），提供审查用的斜杠命令。

不用委派模式时，要先 `ocr config provider` 和 `ocr config model` 配 LLM；交互界面会要求填 API Key，Key 存在哪里 README 没写（以官方 Configuration 文档为准，未确认），优先用环境变量。

可选：仓库根目录有 `action.yml`，可以在 `.github/workflows/` 里引用它，每个 PR 自动审查；LLM Key 通过 GitHub Secrets 注入。
